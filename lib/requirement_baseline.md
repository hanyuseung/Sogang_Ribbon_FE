## 4. 기능 요구사항 상세 (Functional Requirements)

### FR-001 · FR-002. 인증

- **설명:** Supabase Auth를 통한 이메일/비밀번호 인증
- **입력:** 이메일(`@sogang.ac.kr` 권장), 비밀번호
- **출력:** JWT 세션, 유저 정보(id, email, nickname, review_cnt)
- **예외:**
  - 이메일 미인증 상태 → "이메일 인증이 완료되지 않았어요" 안내
  - 잘못된 자격증명 → "이메일 또는 비밀번호가 올바르지 않아요" 안내
- **구현 참고:** `app/login/LoginForm.tsx`, `lib/supabase.ts`, `contexts/AuthContext.tsx`

---

### FR-010 ~ FR-017. 지도 & 리스트

- **카카오맵:** `react-kakao-maps-sdk`의 `Map` + `CustomOverlayMap`으로 커스텀 핀 렌더링
- **필터 파이프라인:** 분류 필터 → 키워드 AND 필터 → 텍스트 검색 → 정렬
- **정렬 로직 (`lib/sort_functions.ts`):**
  - 거리순: Haversine 공식, 기본 기준점 서강대(37.551, 126.9394), 위치 허용 시 현위치
  - 리본별: cardinal×3 + deepred×2 + pink×1 합산 내림차순
  - 가나다순: `String.localeCompare("ko")` 오름차순
- **키워드 필터:** AND 로직 — 선택된 모든 키워드를 보유한 식당만 노출
- **상태 관리:** 분류·키워드·검색어는 `MapSection`이 소유, 위치 정보는 `PlaceListWithSort`가 소유 (Kakao Map 리렌더 방지)
- **구현 참고:** `components/MapSection.tsx`, `components/MapPlaceholder.tsx`, `components/PlaceListWithSort.tsx`

---

### FR-030 ~ FR-033. 리뷰

- **사진:** 최대 5장, `URL.createObjectURL` 로컬 미리보기 (Supabase Storage 업로드는 미연동)
- **키워드:** 8개 고정 옵션 중 최대 3개 선택 필수
- **텍스트:** 비어있으면 제출 불가 (`canSubmit` 검사)
- **수정:** `?reviewId=` 쿼리스트링으로 편집 모드 진입, 기존 내용 자동 로드
- **비로그인 접근:** 로그인 페이지로 리다이렉트 (`?redirect=` 유지)
- **구현 참고:** `app/review/new/ReviewForm.tsx`

---

### FR-041. 엠블럼 (게이미피케이션)

- **등급:** bronze → silver → gold → platinum → diamond (5단계)
- **조건:** `user.review_cnt`가 각 등급의 `review_threshold` 이상이면 해당 등급 부여
- **표시:** 마이페이지에서 현재 등급 + 다음 등급까지 남은 리뷰 수 + 진행 막대
- **트리거:** 리뷰 제출 시 `review_cnt` 증가 후 임계값 체크 (백엔드 로직 필요)

---

### FR-050. 랜덤 식당 추천 (가챠)

- **설명:** 전체 식당 중 랜덤 1개 추천 ("오늘 뭐 먹지?" 기능)
- **진입:** 홈 화면 또는 하단 네비게이션
- **구현 참고:** `app/gacha/page.tsx`, `components/GachaClient.tsx`

## 9. 제약사항 및 가정

- **MVP 범위:** 로그인·지도 탐색·리뷰 작성·마이페이지·가챠 (커뮤니티·어워드 제외)
- **서버 환경:** 서버리스 (Vercel + Supabase)
- **ORM:** Prisma (서버 컴포넌트·API 라우트에서 사용)
- **인증:** Supabase Auth만 사용 (소셜 로그인은 추후 검토)
- **이미지 저장:** 리뷰 사진은 Supabase Storage 연동 예정 (현재 로컬 미리보기만)
- **북마크·엠블럼:** 현재 더미 JSON 데이터 사용, 실 DB 연동 필요
- **어워드:** DB 스키마 존재하나 기능 미개발
